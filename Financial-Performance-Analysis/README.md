## 📊 Financial Performance Analysis — Capstone Project

### 📌 Project Overview
An end-to-end financial analytics capstone project focused on analyzing financial transactions, evaluating business performance, validating data quality, and generating actionable insights through SQL, Python, Excel, and Power BI.

The project follows a structured analytics workflow, from data loading and cleaning to KPI analysis, statistical testing, visualization, and final reporting.

### 🎯 Project Objectives
- Analyze financial performance and key business metrics.
- Load, clean, and validate financial transaction data.
- Perform exploratory data analysis (EDA) using Python.
- Calculate core financial KPIs using SQL.
- Analyze trends across time, business units, regions, and vendors.
- Evaluate budget versus actual performance.
- Investigate transaction concentration and data quality issues.
- Apply statistical methods to investigate business questions.
- Develop a Power BI dashboard and communicate business recommendations.

### 🛠️ Tools & Technologies
- **Python:** Pandas, NumPy, Jupyter Notebook
- **SQL:** Data validation, KPI calculations, trend and business analysis
- **Microsoft Excel:** Financial data inspection and analysis
- **Power BI:** Interactive dashboard development
- **Statistics:** Statistical analysis and hypothesis testing
- **GitHub:** Project documentation and version control
