## 📌 Project Overview
This Power BI dashboard analyzes how students' social media usage impacts:
- Mental Health
- Sleep Hours
- Academic Performance
- Relationship Status

- Power BI
- DAX
- Data Modeling
- Data Visualization

- Interactive Story View
- Student Profile (Drill-through)

- Interactive Slicers

- Drill-through
- Star Schema
- Calculated Columns
- DAX Measures
